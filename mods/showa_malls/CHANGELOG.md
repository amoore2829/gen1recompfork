# Changelog

All notable changes to this mod are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-08-17

### Added

- Three registered maps: `SHOWA_MALL_1F`, `SHOWA_MALL_2F` and
  `SHOWA_MALL_TUNNEL`, built on OLIVINE_MART's verified block layout with
  real staircase blocks substituted at the warp cells so the warps fire.
- Working staircases between all three, a carpet exit to Olivine City,
  and a passage door out to Goldenrod Underground.
- Greeter NPCs on the Olivine shopping block and in Goldenrod Underground.
- Four-counter stamp rally (toy floor, record shop, fashion floor, ramen
  stand) with no double-stamping, a `ShowaStickerAlbum` screen behind a
  STAMPS row on the START menu, and 100 MALL POINTS for a full book.
- `stickerCount`, `hasSticker` and `album` exports.
- Suites: 69 pure rules checks (including a guard that every warp sits on
  a warping tile), 10 headless gen-2 checks, and a 16-check Gold driver.
